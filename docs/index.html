InkCrop 聚焦三件事：二值化、稳健框选、按右到左分页导出 PDF。 最新版本已优化长卷性能，并降低左右误裁风险。

  • 6x+PDF 导出提速

快速命令

python simple_binary.py "tests/你的图片.jpg" "outputs/out_binary.jpg" "outputs/out_box.jpg" "outputs/out_a4.pdf"

支持单图处理与批处理脚本 `batch_binary.sh`。

核心能力

围绕“长卷书法可打印”做了专门优化。

稳健框选

使用降采样投影 + 原始外接框兜底策略，防止左右边缘字被激进裁掉。

极速导出

PDF 页先编码为临时 JPEG 再嵌入，显著减少 ReportLab 编码耗时。

长卷分页

自动检测切分候选并按右到左分页，控制列宽适配 A4 打印比例。

快速开始

本地执行 Python 脚本，输出二值图、框选图与 A4 PDF。

1. 安装依赖

python -m pip install opencv-python numpy pillow reportlab scikit-image

2. 单图处理

python simple_binary.py "tests/唐 褚遂良 阴符经21x394.jpg"

3. 批量处理

bash batch_binary.sh

常用参数与策略

BBOX_DETECT_MAX_SIDE=2400：框选检测降采样最大边。

BBOX_PADDING_RATIO=0.03：检测框上下左右补边比例。

BBOX_MIN_PROJ_COVER_RATIO=0.85：投影框兜底阈值。

PDF_PAGE_MARGIN_MM=5.0：A4 页面边距（毫米）。

PDF_IMAGE_JPEG_QUALITY=90：PDF 图像嵌入质量。

GitHub Pages 部署

仓库内已包含自动部署 workflow，推送后即可发布。

  1. 将代码推送到 GitHub 仓库的默认分支（建议 main）。
  2. 在仓库设置中进入 Settings -> Pages。
  3. Source 选择 GitHub Actions，等待 workflow 完成部署。

页面内容来自 docs/ 目录，入口为 docs/index.html。
