CLI 快速开始

如果你更习惯本地脚本，保留了 Python 版本同等流程。

1. 安装依赖

python -m pip install opencv-python numpy pillow reportlab scikit-image

2. 单图处理

python simple_binary.py "tests/唐 褚遂良 阴符经21x394.jpg"

3. 批量处理

bash batch_binary.sh

GitHub Pages 部署

仓库内已包含自动部署 workflow，推送后即可发布。

  1. 将代码推送到 GitHub 仓库默认分支（`main` 或 `master`）。
  2. 在仓库设置打开 `Settings -> Pages`。
  3. Source 选择 `GitHub Actions`，等待部署完成。
